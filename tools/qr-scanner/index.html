QR Code 掃描器使用說明

本工具讓你不需要安裝任何 App，就能直接在瀏覽器解讀 QR Code。使用方式有兩種：一是點擊「開始掃描」授權使用鏡頭，將畫面對準 QR Code 即可即時辨識；二是直接上傳含有 QR Code 的圖片檔案，上傳後會自動解碼，不需要額外按鈕。

在電腦前常見的做法是上傳圖片：無論是截圖、相機拍攝的照片還是網路上儲存的 QR Code 圖檔，拖入或選擇檔案後即可自動讀取。工具會對整張圖片進行解碼嘗試，即使 QR Code 不是完美正面或有些許傾斜，也能提高辨識成功率。

掃描結果會顯示 QR Code 內含的原始內容，可能是網址、純文字、聯絡資訊或 Wi-Fi 設定。若內容是網址，工具會提供方便的開啟與複製按鈕；若為其他格式的資料，也會以易讀方式呈現。

所有辨識處理都在瀏覽器本機完成，掃描或上傳的圖片不會傳送到任何伺服器。請放心使用，尤其適合處理包含敏感資訊的 QR Code。

常見問題 FAQ

為什麼鏡頭掃描一直失敗？

請確認瀏覽器已授權鏡頭權限、環境光線充足、QR Code 完整位於畫面框內且對焦清晰。過度反光或模糊會影響辨識。

上傳圖片後沒有自動解碼？

請確認圖片中的 QR Code 清晰、完整且解析度足夠。若圖片被裁切或嚴重失焦，可嘗試重新拍攝後再上傳。

掃描的圖片會被上傳嗎？

不會。所有解碼都在瀏覽器本機執行，圖片不會離開你的裝置，安全且有隱私保障。
