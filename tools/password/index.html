密碼產生器使用說明

使用弱密碼是帳號被盜的首要原因，例如生日、姓名或簡單數字組合都極易被破解。本工具可依你的需求隨機產生高強度密碼，並即時顯示強度評級，幫助你為不同服務建立獨一無二的安全密碼。

使用時可依網站要求調整參數：長度（建議至少 12 個字元）、是否包含大寫字母、小寫字母、數字與特殊符號。一般來說，包含全部四類字元且長度達 16 位以上的密碼，被暴力破解所需的時間將大幅拉長。工具的強度指示會根據字元組合與長度即時評估，綠色代表安全性足夠。

產生後點擊「複製」即可將密碼複製到剪貼簿。為了安全考量，請勿在公共電腦或截圖中保存密碼，建議使用瀏覽器內建的密碼管理或專業密碼管理工具（如 Bitwarden、1Password）集中儲存，避免每個帳號共用相同密碼。

所有密碼都是在你瀏覽器的本機隨機產生，不會傳送到任何伺服器，也不留任何紀錄。本工具使用瀏覽器的加密級隨機數 API（Crypto API），確保隨機品質足夠應付安全需求。

常見問題 FAQ

多長才算安全的密碼？

建議至少 12 個字元，16 個以上更佳。長度比複雜度更重要——長密碼組合數遠多於短密碼，破解難度以指數成長。

產生的密碼會被儲存或外洩嗎？

不會。密碼在你的瀏覽器本機以 Crypto API 隨機產生，完全不經伺服器，也無任何紀錄，可放心使用。

我可以自己選喜歡的密碼組合嗎？

可以。你可以任意勾選或取消大寫、小寫、數字與符號選項，並調整長度，工具會依你的偏好即時產生新的組合。
